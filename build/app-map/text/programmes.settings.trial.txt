Trial settings

If you offer trial sessions for this programme, you can set them up here.

Trial type
None
Free Trial (Single Session)
Clients enrol for one free trial session. No payment is required, and Zooza will not generate any debt for this booking.
Free Trial (Multiple Sessions)
Clients enrol once and gain free access to all upcoming sessions within the trial period. Zooza will not generate any debt.Use the “Trial Length” setting to define how many days the trial lasts after the first session is selected.
More
Paid Trial (Single Session)
Clients enrol for one paid trial session. Zooza will generate debt equal to the price of a single session.
Paid Trial (Multiple Sessions)
Clients enrol once and pay for multiple upcoming sessions within the trial period. Zooza will generate debt for each session based on the price settings. Use the “Trial Length” setting to control how long the client remains enrolled.
More
Lead collection
Use this if you don't want to allow clients to enrol in class sessions directly instead enrol in an empty class, and you’ll enrol them into classes manually.
