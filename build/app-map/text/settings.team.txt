Attendance management settings for instructors:
Full report (attended, did not attend, cancelled, choose a make-up session)

Availability management settings for instructors:
Full report (Users manage their own availability and absences)
Restricted administration (Any change to availability and absences must be approved by the owner)
Absences only (Instructor can only request absences)
Session cancellation policy
None
Make-up session required - instructor cannot cancel a session without setting a make-up session
Full - instructor can freely cancel any session he's entitled to
Allow instructors to create session substitutions
No
This setting will allow instructors to manage substitutions by themselves. Each substitution needs to be confirmed by the substituting instructor and upon each new substitution request, instructor will need to select an administator which will get e-mail notification about this change.
More
Allow all instructor roles to send email or SMS messages to clients from the session detail.
Yes
This will enable instructors to send quick messages directly from the session detail. The message will be sent to all of session's participants.
Allow external instructors to see client's personal data in session detail
No
By default all personal data about clients are hidden for external instructors. If enabled, external instructors will be able to see personal data for example in case of emergency when they need to reach parents quickly. Each display of these data is logged in the system.
More
Allow instructors to see financial information
Yes
When turned off, all instructor roles (main, regular and external instructors) lose access to client financial information: the Payments section, payment amounts on bookings, invoices, credits and financial reports. Owners, assistants and receptionists are unaffected.
More
Allow main instructors to access the Payments section
Yes
Grant or deny access to the Payments section of the application. This includes: Payments overview, Received payments, Scheduled payments and Invoices
