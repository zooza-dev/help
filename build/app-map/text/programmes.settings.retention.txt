Continuation for this programme's clients

What happens to this programme's clients when their class ends?

Decide what should happen after a class ends. For group classes, you can suggest which classes students should continue in. For individual sessions, they can simply sign up again.

Auto-enrolment type
None
Suggest classes
We’ll show clients a set of suitable classes based on your criteria. If they choose to continue, they can enrol in one with a single click—no need to fill in their details again.
Duplicate current class
For 1-to-1 classes only: When a client agrees to continue, Zooza will prepare an identical version of the current class for the future. You just review and approve.
Notify the client N days before the class ends
+
-

Keep client in auto-enrolment for N days
+
-
The client will see the auto-enrolment offer in their profile for the specified number of days. Set this to 0 to use the default value (30 days).
Auto-enrollment message
This message will be sent to the client as a notification that their group is ending and auto-enrolment is available.

When this programme's clients are in auto-enrolment, which classes are they shown?

These settings apply to this programme's own clients once their class ends and they enter auto-enrolment. They filter which classes (offered by any programme) those clients are shown. They have no effect on clients coming from other programmes.
