Settings for programmes

General settings for all programmes in your account.

Set a limit for cancelling a scheduled session
Yes
With this setting, you determine when clients can cancel the scheduled sessions.
Allow cancellations after the limit
No
If the option of make-up sessions is enabled for a particular programme and the client cancels after the set limit, the make-up session will not be granted to this client but it will at least free up a slot for others to use their make-up sessions. The attendance record for the client will show "Did not attend".
More
Limit type
Fixed time (the day before the session at a specified hour)
Relative time (number of hours before the start of the session)
Number of days:
+
-
The number of days before client may cancel the session. The value 0 means on the day of the session.
The time prior to which you allow clients to cancel a scheduled session. Specify the exact time the day before the scheduled session. After this time, the user will be informed that he/she has missed the limit for cancellations.
Time 
Fill in the exact time in the format e.g. 22:00 and save the changes.
Block cancellations on weekends and holidays
No
If this setting is enabled, the cancellation limit for Monday sessions will be Friday at midnight.
Time limit in hours for creating a tailored make-up session:
+
-
The earliest time (the number of hours before the regular session) when the client can create a make-up sessions. If the blocking of cancelations on weekends is enabled, the creation of tailored make-up sessions on weekends will also be blocked. If zero is entered, the default value of 24 hours will be used.
More
Time restriction in hours for offering a regular make-up session
+
-
Set the time limit in hours before a session starts, after which it won’t be offered as a make-up option. For example, a session starting at 3:00 PM with a 1-hour limit won’t be available after 2:00 PM.
Allow refund requests
Yes
Clients can request a refund when they cancel an eligible session. Requests appear on the booking detail, where you approve or deny them. Approving records your decision. You still issue the refund itself through your payment provider.

Require instructors to complete summaries of sessions for their clients
No
If this option is enabled and the instructor does not complete the summary after a session, a reminder will be sent to the instructor the next day. If he/she does not complete the summary even then, this option will be locked the following day.

Automatically cancel a session if it is empty
No
If the last client cancels, the session is automatically changed to the Cancelled status
Automatically close attendance
+
-
The number indicates the number of days after which attendance will be automatically closed for all participants who will have it in the Will be present status at the given time. The setting is disabled if its value is equal to zero. Automatic attendance closure is a one-off event, attendance will be automatically closed only for participants who will be logged in to the session at the closing time.
More
Custom Customer ID
Format customer ID based on your settings. Allowed values are: Unique ID - U (U1-U10). Number from 1-10 denotes minimum length of number. E.g. given that unique id number is 123, command: U6 will produce: 000123. Company (C - company Id as is, c - company id as 6 digit number). Each symbol needs to be enclosed within curly brackets. Valid examples: {C}{U6} = 123000123, 43-{U6} = 43-000123. Resulting id can contain also string literals along with special characters.
