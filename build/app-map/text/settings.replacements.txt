Make-up sessions behavior
Set transfered make-up sessions
At the end of the class, make-up sessions up to your setting will be transferred and new expiration date will be set for them. This way your clients will still be able to use their make-up sessions in the next period/programme but only up to the limit you choose.
More
All make-up sessions expire at the end of the class.
The day the class ends, all valid make-up sessions will expire and be voided.
All make-up sessions expire after the preset number of days
The end of the class won’t affect make-up sessions at all. They will naturally expire when their date comes.

Enter the number of make-up sessions that the client can use in the next billing period. This number will only start to be deducted after the class has finished. If you leave a value of 0, it will mean that the function is disabled.
